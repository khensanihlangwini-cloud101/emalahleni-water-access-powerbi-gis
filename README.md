# eMalahleni Water Access: Power BI and GIS Analysis

## Project overview

This project analyses household water access in eMalahleni Local Municipality, Mpumalanga, using Power BI and GIS.

## Business question

Which wards or communities in eMalahleni have the lowest access to piped water, and where should water-service interventions be prioritised?

## Tools

- Power BI Desktop
- Power Query
- DAX
- QGIS or ArcGIS
- Microsoft Excel
- GitHub

## Project status

In progress.

## Planned outputs

- Cleaned and documented water-access dataset
- GIS map showing water-access patterns
- Power BI dashboard
- Data insights and recommendations
- Portfolio case study
